## Anh Tu Bakery — Website Quản Lý Bán Sỉ & Bán Lẻ

## 1. Tổng quan kiến trúc

Hệ thống áp dụng mô hình **MVC phân lớp** (Layered MVC), triển khai theo Spring Boot:

```
┌─────────────────────────────────────────────────────────────────┐
│                        CLIENT (Browser)                         │
│         HTML/CSS/JS + Thymeleaf / REST Fetch / SSE              │
└────────────────────────────┬────────────────────────────────────┘
                             │ HTTP / SSE
┌────────────────────────────▼────────────────────────────────────┐
│                    CONTROLLER LAYER                             │
│   RetailController │ WholesaleController │ AdminController      │
│   AuthController   │ ReportController    │ SSEController        │
└────────────────────────────┬────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────┐
│                     SERVICE LAYER                               │
│   OrderService │ PricingService │ ShippingService               │
│   AgentService │ ProductService │ NotificationService           │
│   QrPaymentService │ ReportService │ DistanceCalculator         │
└────────────────────────────┬────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────┐
│                   REPOSITORY LAYER (JPA)                        │
│   UserRepository │ AgentRepository │ OrderRepository            │
│   ProductRepository │ OrderItemRepository                       │
└────────────────────────────┬────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────┐
│               DATABASE — MySQL / PostgreSQL / H2                │
└─────────────────────────────────────────────────────────────────┘
```

**Cấu hình tập trung:** Mọi tham số nghiệp vụ (tọa độ lò bánh, bán kính phục vụ, số điện thoại admin, mức giá sỉ) được khai báo trong `application.yml` — không hardcode trong source code.

### 2.5 Bảng trạng thái đơn hàng lẻ

| Trạng thái | Mô tả | Chuyển tiếp |
|------------|-------|-------------|
| `PENDING` | Vừa đặt, chờ thanh toán | → `PAID` khi Admin xác nhận |
| `PAID` | Đã thanh toán, chờ làm | → `PREPARING` khi bắt đầu |
| `PREPARING` | Đang chuẩn bị | → `READY` khi xong |
| `READY` | Xong, chờ lấy / chờ ship | → `COMPLETED` hoặc `DELIVERING` |
| `DELIVERING` | Đang giao (chỉ GIAO_HANG) | → `COMPLETED` |
| `COMPLETED` | Hoàn thành | Kết thúc |
| `CANCELLED` | Hủy (Admin xử lý thủ công) | Kết thúc |

## 3. Core Services — Mô tả interface chính

### 3.1 `DistanceCalculator`

```java
public interface DistanceCalculator {
    /**
     * Tính khoảng cách đường thẳng (km) giữa 2 tọa độ
     * bằng công thức Haversine.
     * @param lat1, lon1 : Tọa độ điểm 1 (lò bánh)
     * @param lat2, lon2 : Tọa độ điểm 2 (địa chỉ giao)
     * @return khoảng cách tính bằng km (double)
     */
    double calculate(double lat1, double lon1, double lat2, double lon2);
}
```

**Công thức Haversine:**
```
a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2)
c = 2·atan2(√a, √(1−a))
d = R·c      (R = 6371 km)
```

### 3.2 `ShippingFeeCalculator`

```java
public interface ShippingFeeCalculator {
    /**
     * Tính phí giao hàng lũy tiến theo km.
     * @param distanceKm : khoảng cách (km), kết quả từ DistanceCalculator
     * @return phí giao hàng (VNĐ, làm tròn đến 500đ)
     */
    int calculate(double distanceKm);
}
```

### 3.3 `WholesalePricingService`

```java
public interface WholesalePricingService {
    /**
     * Tính đơn giá và tổng tiền đơn sỉ theo bậc thang.
```

### 3.4 `NotificationService`

```java
public interface NotificationService {
    /**
     * Gửi sự kiện SSE đến client đang lắng nghe theo orderId.
     * @param orderId    : mã đơn hàng
     * @param event      : loại sự kiện (ORDER_CONFIRMED, PAYMENT_CONFIRMED, READY)
     * @param deliveryMethod : TU_LAY hoặc GIAO_HANG (quyết định nội dung message)
     */
    void pushOrderStatus(Long orderId, OrderEvent event, DeliveryMethod deliveryMethod);
}
```

### 3.5 `QrPaymentService`

```java
public interface QrPaymentService {
    /**
     * Trả về thông tin hiển thị trên màn hình QR.
     * Tách biệt để sau nâng cấp Webhook không ảnh hưởng Controller.
     */
    QrPaymentInfo generateQrInfo(Order order);

    /**
     * Admin xác nhận thanh toán thủ công.
     * Chuyển đơn PENDING → PAID, gửi SSE xác nhận.
     */
    void confirmPayment(Long orderId, Long adminId);
}
```

## 4. Cấu hình `application.yml` — Tham số nghiệp vụ

```yaml
bakery:
  # Tọa độ lò bánh mì (cập nhật trước khi demo)
  location:
    latitude: 15.1234567
    longitude: 108.9876543

  # Bán sỉ
  wholesale:
    min-quantity: 50
    tier1-max-quantity: 199
    tier1-price: 1500        # VNĐ/ổ
    tier2-price: 1300        # VNĐ/ổ
    max-delivery-radius-km: 5.0

  # Phí giao hàng lẻ
  shipping:
    base-fee: 10000          # 0–2km
    tier2-start-km: 2.0
    tier2-rate: 3500         # VNĐ/km (2–5km)
    tier3-start-km: 5.0
    tier3-rate: 4000         # VNĐ/km (5–10km)
    tier4-start-km: 10.0
    tier4-rate: 5000         # VNĐ/km (>10km)
    warning-distance-km: 50.0

  # Thông báo
  admin:
    phone: "0779409567"
```

## 5. Phân quyền & Bảo mật tổng quan

| Endpoint pattern | ADMIN | AGENT | Khách lẻ |
|-----------------|-------|-------|----------|
| `/admin/**` | ✅ | ❌ | ❌ |
| `/agent/**` | ✅ | ✅ (chính mình) | ❌ |
| `/wholesale/register` | ❌ | ✅ (chưa có tài khoản) | ❌ |
| `/menu`, `/order/retail` | ✅ | ✅ | ✅ |
| `/api/orders/{id}/stream` (SSE) | ✅ | ✅ | ✅ (token đơn) |

Tất cả form POST được bảo vệ bằng **CSRF token**. Truy vấn DB dùng **JPA Parameterized Query**, không ghép chuỗi SQL.
