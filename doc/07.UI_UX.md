## 3. CHỮ VIẾT (TYPOGRAPHY)

### 3.1 Hệ thống phông chữ

| Vai trò | Font | Lý do chọn |
|---------|------|-----------|
| **Tiêu đề chính (H1, H2)** | `Pacifico` (Google Fonts — miễn phí) | Nét bo tròn, viết tay mộc mạc, đậm chất thủ công — giống kiểu chữ trên logo |
| **Tiêu đề phụ (H3, H4)** | `Nunito` Bold | Sans-serif tròn, bắc cầu giữa thủ công và hiện đại |
| **Nội dung thường (Body)** | `Nunito` Regular / Light | Dễ đọc, nét mảnh, tương phản tốt trên mọi nền |
| **Giá tiền, số liệu** | `Nunito` ExtraBold | Nổi bật, rõ ràng |
| **Nhãn nhỏ, caption** | `Nunito` Italic | Nhẹ nhàng, không lấn át |

> **Lý do chọn Pacifico:** Đây là font viết tay bo tròn, nét mộc mạc, thể hiện đúng tinh thần "handcrafted / artisan" mà không cần font trả phí. Kết hợp với Nunito tạo cặp đôi ấm áp, thân quen, phù hợp quán bánh mì gia đình.

### 3.2 Thang kích cỡ chữ

| Cấp độ | Kích cỡ (desktop) | Kích cỡ (mobile) | Font |

## 4. HIỆU ỨNG NỀN VÀ CHẤT LIỆU (TEXTURE & BACKGROUND)

### 4.1 Nền giấy Kraft — Trang chủ & Hero

Sử dụng **CSS texture pattern** mô phỏng giấy gói bánh mì / giấy Kraft nhăn nhẹ:

```css
/* Nền giấy Kraft — dùng noise + gradient chồng lên nhau */
body {
  background-color: #FFFBEB;
  background-image:
    url("data:image/svg+xml,..."), /* SVG grain texture */
    linear-gradient(135deg, #FEF3C7 0%, #FFFBEB 50%, #FDE68A 100%);
}

/* Hoặc dùng CSS noise cho hiệu ứng giấy nhăn */
.hero-section {
  background-color: #F59E0B;
  background-image: url('/images/kraft-paper-texture.png');
  background-blend-mode: multiply;
  opacity: 0.95;
}
```

### 4.2 Phân lớp nền theo section

| Section | Nền | Hiệu ứng |
|---------|-----|----------|
| Header | `#92400E` solid | Không texture (sạch, dễ đọc) |
| Hero | `#F59E0B` + Kraft texture | Overlay mờ nhẹ, mascot nổi bật |
| Menu lẻ | `#FFFBEB` + grain nhẹ | Card nổi lên trên nền kem |
| Giới thiệu / Story | `#78350F` tối | Chữ vàng — cảm giác ấm cúng tối |
| Footer | `#92400E` + pattern truyền thống | Hoa văn mờ từ logo |

### 5.6 Thẻ chọn hình thức nhận hàng

```css
.pickup-card {
  border: 2px solid #F59E0B;
  border-radius: 16px;
  padding: 20px;
  cursor: pointer;
  transition: all 0.2s ease;
  background: #FFFBEB;
}

.pickup-card:hover,
.pickup-card.selected {
  background: linear-gradient(135deg, #FEF3C7, #FFFBEB);
  border-color: #B91C1C;
  border-width: 3px;
  box-shadow: 0 4px 16px rgba(185, 28, 28, 0.2);
  transform: translateY(-2px);
}

.pickup-card .icon {
  font-size: 36px;  /* emoji icon lớn */
}

.pickup-card .price-tag {
  color: #059669;   /* xanh lá — miễn phí */
  font-family: Nunito;
  font-weight: 800;
}
```

## 8. NGUYÊN TẮC UX (UX PRINCIPLES)

### 8.1 Ưu tiên Mobile-first
- Tất cả nút bấm **tối thiểu 44×44px** (tiêu chuẩn Apple HIG) để dễ bấm trên điện thoại.
- Không có hover-only state quan trọng — mọi thứ phải tương tác được bằng chạm.
- Form đặt hàng tối giản — chỉ hỏi đúng thứ cần thiết, không hỏi dư.

### 8.2 Phản hồi tức thì (Immediate Feedback)
- Giá sỉ cập nhật **ngay khi gõ số lượng** — không cần bấm nút tính.
- Phí ship hiển thị **ngay khi nhập tọa độ** — không cần reload trang.
- Nút thêm vào giỏ: animation nhỏ (bounce nhẹ 0.3s) để xác nhận đã thêm thành công.

### 8.3 Trạng thái rõ ràng
- Luôn hiển thị trạng thái đơn hàng bằng **màu sắc + icon + chữ** — không chỉ dựa vào màu.
- Thông báo lỗi: **đỏ nhạt nền + icon ⚠ + hướng dẫn sửa** — không chỉ tô đỏ ô input.
- Loading state: skeleton placeholder giữ layout ổn định, không bị giật.

### 8.4 Ngôn ngữ thân quen, gần gũi
| Thay vì | Dùng |
|---------|------|
| "Submit" | "Đặt hàng ngay" |
| "Confirm payment" | "Xác nhận đã chuyển tiền" |
| "Out of delivery zone" | "Rất tiếc, khu vực bạn chưa được hỗ trợ giao" |

| "Order status: READY" | "🎉 Món của bạn đã xong! Mời đến lấy." |

Đây là điểm nhận diện độc đáo của website — thẻ chọn **Tự đến lấy / Giao hàng** được thiết kế như **mảnh phiếu xé bánh mì**, có cạnh răng cưa nhỏ ở trên, tạo cảm giác đang xé phiếu từ cuộn vé thủ công. Khi được chọn, phiếu "đóng dấu" đỏ góc trên.

```
  ╭─────────────────────╮       ╭─────────────────────╮
  │ ⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯ │  →   │ ⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯ │
  │   🏠                │       │   🏠          ✔      │
  │   Tự đến lấy        │       │   Tự đến lấy        │
  │   Miễn phí          │       │   Miễn phí          │
  ╰─────────────────────╯       ╰─────────────────────╯
     (chưa chọn)                    (đã chọn — có dấu tick)
```

CSS: cạnh trên dùng `border-top: 3px dashed #F59E0B` mô phỏng mép phiếu xé.
