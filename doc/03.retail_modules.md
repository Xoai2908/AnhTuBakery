### 2.4 Thuật toán tính phí giao hàng lũy tiến

**Công thức phân chặng:**

```
Phí(d) =
  d ≤ 2km            → 10.000đ
  2km < d ≤ 5km      → 10.000 + (d - 2) × 3.500đ
  5km < d ≤ 10km     → [Phí tại 5km] + (d - 5) × 4.000đ
                     = 10.000 + 3 × 3.500 + (d - 5) × 4.000
                     = 20.500 + (d - 5) × 4.000
  d > 10km           → [Phí tại 10km] + (d - 10) × 5.000đ
                     = 20.500 + 5 × 4.000 + (d - 10) × 5.000
                     = 40.500 + (d - 10) × 5.000
  d > 50km           → Tính như trên + hiển thị cảnh báo, không tự chặn
```

**Cài đặt Java:**

```java
@Service
public class ShippingFeeCalculatorImpl implements ShippingFeeCalculator {

    // Giá trị inject từ application.yml
    private final double baseFee = 10_000;
    private final double tier2Rate = 3_500;   // 2–5km
    private final double tier3Rate = 4_000;   // 5–10km
    private final double tier4Rate = 5_000;   // >10km

    @Override
    public int calculate(double distanceKm) {
        double fee;

        if (distanceKm <= 2.0) {
            fee = baseFee;
        } else if (distanceKm <= 5.0) {
            fee = baseFee + (distanceKm - 2.0) * tier2Rate;
        } else if (distanceKm <= 10.0) {
            double feeAt5km = baseFee + 3.0 * tier2Rate; // 20.500
            fee = feeAt5km + (distanceKm - 5.0) * tier3Rate;
        } else {
            double feeAt10km = baseFee + 3.0 * tier2Rate + 5.0 * tier3Rate; // 40.500
            fee = feeAt10km + (distanceKm - 10.0) * tier4Rate;
        }

        // Làm tròn lên đến 500đ gần nhất
        return (int)(Math.ceil(fee / 500.0) * 500);
    }
}
```

**Bảng ví dụ:**

| Khoảng cách | Phí ship (trước làm tròn) | Phí ship (sau làm tròn) |
|-------------|--------------------------|------------------------|
| 1,0 km | 10.000đ | 10.000đ |
| 1,5 km | 10.000đ | 10.000đ |
| 2,0 km | 10.000đ | 10.000đ |
| 3,5 km | 15.250đ | 15.500đ |
| 5,0 km | 20.500đ | 20.500đ |
| 7,0 km | 28.500đ | 28.500đ |
| 10,0 km | 40.500đ | 40.500đ |
| 12,0 km | 50.500đ | 50.500đ |

### 2.4 Thuật toán tính phí giao hàng lũy tiến

**Công thức phân chặng:**

```
Phí(d) =
  d ≤ 2km            → 10.000đ
  2km < d ≤ 5km      → 10.000 + (d - 2) × 3.500đ
  5km < d ≤ 10km     → [Phí tại 5km] + (d - 5) × 4.000đ
                     = 10.000 + 3 × 3.500 + (d - 5) × 4.000
                     = 20.500 + (d - 5) × 4.000
  d > 10km           → [Phí tại 10km] + (d - 10) × 5.000đ
                     = 20.500 + 5 × 4.000 + (d - 10) × 5.000
                     = 40.500 + (d - 10) × 5.000
  d > 50km           → Tính như trên + hiển thị cảnh báo, không tự chặn
```

### 2.4 Thuật toán tính phí giao hàng lũy tiến

**Công thức phân chặng:**

```
Phí(d) =
  d ≤ 2km            → 10.000đ
  2km < d ≤ 5km      → 10.000 + (d - 2) × 3.500đ
  5km < d ≤ 10km     → [Phí tại 5km] + (d - 5) × 4.000đ
                     = 10.000 + 3 × 3.500 + (d - 5) × 4.000
                     = 20.500 + (d - 5) × 4.000
  d > 10km           → [Phí tại 10km] + (d - 10) × 5.000đ
                     = 20.500 + 5 × 4.000 + (d - 10) × 5.000
                     = 40.500 + (d - 10) × 5.000
  d > 50km           → Tính như trên + hiển thị cảnh báo, không tự chặn
```

**Cài đặt Java:**

```java
@Service
public class ShippingFeeCalculatorImpl implements ShippingFeeCalculator {

    // Giá trị inject từ application.yml
    private final double baseFee = 10_000;
    private final double tier2Rate = 3_500;   // 2–5km
    private final double tier3Rate = 4_000;   // 5–10km
    private final double tier4Rate = 5_000;   // >10km

    @Override
    public int calculate(double distanceKm) {
        double fee;

        if (distanceKm <= 2.0) {
            fee = baseFee;
        } else if (distanceKm <= 5.0) {
            fee = baseFee + (distanceKm - 2.0) * tier2Rate;
        } else if (distanceKm <= 10.0) {
            double feeAt5km = baseFee + 3.0 * tier2Rate; // 20.500
            fee = feeAt5km + (distanceKm - 5.0) * tier3Rate;
        } else {
            double feeAt10km = baseFee + 3.0 * tier2Rate + 5.0 * tier3Rate; // 40.500
            fee = feeAt10km + (distanceKm - 10.0) * tier4Rate;
        }

        // Làm tròn lên đến 500đ gần nhất
        return (int)(Math.ceil(fee / 500.0) * 500);
    }
}
```

**Bảng ví dụ:**

| Khoảng cách | Phí ship (trước làm tròn) | Phí ship (sau làm tròn) |
|-------------|--------------------------|------------------------|
| 1,0 km | 10.000đ | 10.000đ |
| 1,5 km | 10.000đ | 10.000đ |
| 2,0 km | 10.000đ | 10.000đ |
| 3,5 km | 15.250đ | 15.500đ |
| 5,0 km | 20.500đ | 20.500đ |
| 7,0 km | 28.500đ | 28.500đ |
| 10,0 km | 40.500đ | 40.500đ |
| 12,0 km | 50.500đ | 50.500đ |

## 3. Xử lý lỗi & Edge Cases — Phân hệ Lẻ

| Tình huống | Hành vi hệ thống |
|------------|-----------------|
| Chưa chọn hình thức nhận hàng | Highlight ô chọn đỏ, không cho qua bước tiếp |
| Chọn "Giao hàng" nhưng chưa nhập địa chỉ | "Vui lòng nhập địa chỉ giao hàng để tính phí ship." |
| Tọa độ không hợp lệ (ngoài range) | "Tọa độ không hợp lệ. Vui lòng nhập lại." |
| Bơ đậu chưa chọn Sữa/Đường | Disabled nút thêm giỏ, highlight radio đỏ |
| Giỏ hàng trống bấm Đặt hàng | "Giỏ hàng đang trống. Vui lòng chọn món." |
| Khoảng cách > 50km | Hiển thị cảnh báo + phí ước tính, không chặn |
| Sản phẩm vừa bị Admin tắt | Nếu đã trong giỏ: giữ nguyên. Nếu load mới: không hiển thị |
| Đơn đã xác nhận muốn hủy | Hiển thị: "Để hủy đơn, vui lòng liên hệ 0779409567." |
