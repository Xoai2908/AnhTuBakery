## 1. Thuật Toán Tổng Hợp Doanh Thu Cuối Ngày (FR-08)

### 1.1 Các truy vấn gom nhóm chính

#### Truy vấn 1 — Tổng doanh thu theo loại đơn và hình thức nhận

```sql
SELECT
    o.order_type,                          -- RETAIL | WHOLESALE
    o.delivery_type,                       -- PICKUP | DELIVERY | null (sỉ)
    COUNT(o.id)           AS order_count,
    SUM(o.subtotal)       AS subtotal_sum,
    SUM(o.shipping_fee)   AS shipping_sum,
    SUM(o.total_amount)   AS total_sum
FROM orders o
WHERE
    o.status = 'COMPLETED'
    AND DATE(o.created_at) BETWEEN :fromDate AND :toDate
GROUP BY
    o.order_type,
    o.delivery_type
ORDER BY
    o.order_type, o.delivery_type;
```

#### Truy vấn 2 — Số lượng từng món bán ra (Bánh mì & Nước)

```sql
SELECT
    p.category,             -- BANH_MI | NUOC
    p.name,                 -- Tên sản phẩm
    oi.variant_label,       -- NULL cho bánh mì, "Ly nhỏ"/"Ly lớn" cho nước
    oi.topping_choice,      -- NULL hoặc "Sữa"/"Đường" (bánh mì bơ đậu)
    SUM(oi.quantity)        AS qty_sold
FROM order_items oi
JOIN products p ON oi.product_id = p.id
JOIN orders o   ON oi.order_id   = o.id
WHERE
    o.order_type = 'RETAIL'
    AND o.status = 'COMPLETED'
    AND DATE(o.created_at) BETWEEN :fromDate AND :toDate
GROUP BY
    p.category, p.name, oi.variant_label, oi.topping_choice
ORDER BY
    p.category, p.name, oi.variant_label;
```

#### Truy vấn 3 — Số lượng từng loại Xôi (có tách size)

```sql
SELECT
    p.name                  AS product_name,
    oi.variant_label        AS size,          -- "Hộp nhỏ" | "Hộp lớn"
    SUM(oi.quantity)        AS qty_sold,
    SUM(oi.unit_price * oi.quantity) AS revenue
FROM order_items oi
JOIN products p ON oi.product_id = p.id
JOIN orders o   ON oi.order_id   = o.id
WHERE
    p.category = 'XOI'
    AND o.status = 'COMPLETED'
    AND DATE(o.created_at) BETWEEN :fromDate AND :toDate
GROUP BY
    p.name, oi.variant_label
ORDER BY
    p.name, oi.variant_label;
```

#### Truy vấn 4 — Tổng mì ổ sỉ đã giao

```sql
SELECT
    a.store_name            AS agent_name,
    SUM(oi.quantity)        AS total_loaves,
    SUM(o.total_amount)     AS revenue
FROM orders o
JOIN order_items oi ON oi.order_id = o.id
JOIN agents a       ON o.agent_id  = a.id
WHERE
    o.order_type = 'WHOLESALE'
    AND o.status = 'COMPLETED'
    AND DATE(o.created_at) BETWEEN :fromDate AND :toDate
GROUP BY
    a.store_name
ORDER BY
    total_loaves DESC;
```

#### Truy vấn 5 — Đơn chưa xử lý (cần Admin chú ý)

```sql
SELECT
    o.id,
    o.order_type,
    o.delivery_type,
    o.status,
    o.total_amount,
    o.created_at,
    o.customer_name,
    o.customer_phone
FROM orders o
WHERE
    o.status IN ('PENDING', 'PAID')
    AND DATE(o.created_at) = :date   -- mặc định: hôm nay
ORDER BY
    o.created_at ASC;                -- đơn cũ nhất lên đầu
```

### 1.2 Dự báo vật tư sản xuất ngày mai

Truy vấn phụ giúp Admin chuẩn bị nguyên liệu dựa trên xu hướng 7 ngày gần nhất:

```sql
-- Trung bình số lượng mỗi topping trong 7 ngày gần nhất
SELECT
    p.name,
    oi.topping_choice,
    ROUND(AVG(daily.qty), 0) AS avg_daily_qty
FROM (
    SELECT
        oi.product_id,
        oi.topping_choice,
        DATE(o.created_at)   AS sale_date,
        SUM(oi.quantity)     AS qty
    FROM order_items oi
    JOIN orders o ON oi.order_id = o.id
    WHERE
        o.status = 'COMPLETED'
        AND o.created_at >= CURRENT_DATE - INTERVAL 7 DAY
    GROUP BY oi.product_id, oi.topping_choice, DATE(o.created_at)
) daily
JOIN products p ON daily.product_id = p.id
GROUP BY p.name, oi.topping_choice
ORDER BY p.name;
```

## 3. Thiết Kế Bộ Lọc Báo Cáo

### 3.1 Các tham số lọc hợp lệ

| Tham số | Kiểu | Giá trị mặc định | Mô tả |
|---|---|---|---|
| `fromDate` | `LocalDate` | Hôm nay | Ngày bắt đầu |
| `toDate` | `LocalDate` | Hôm nay | Ngày kết thúc |
| `orderType` | Enum | `ALL` | `ALL` \| `RETAIL` \| `WHOLESALE` |
| `deliveryType` | Enum | `ALL` | `ALL` \| `PICKUP` \| `DELIVERY` |

> **Ràng buộc:** `toDate >= fromDate`. Khoảng cách tối đa 90 ngày để tránh query nặng.

### 3.2 DTO bộ lọc (Spring MVC)

```java
@Data
public class ReportFilterDto {

    @DateTimeFormat(iso = DateTimeFormat.ISO.DATE)
    private LocalDate fromDate = LocalDate.now();

    @DateTimeFormat(iso = DateTimeFormat.ISO.DATE)
    private LocalDate toDate = LocalDate.now();

    private OrderType orderType = OrderType.ALL;

    private DeliveryTypeFilter deliveryType = DeliveryTypeFilter.ALL;

    @AssertTrue(message = "toDate phải >= fromDate")
    public boolean isDateRangeValid() {
        return !toDate.isBefore(fromDate);
    }

    @AssertTrue(message = "Khoảng cách tối đa 90 ngày")
    public boolean isDateRangeNotTooWide() {
        return ChronoUnit.DAYS.between(fromDate, toDate) <= 90;
    }
}
```

### 3.3 Repository với bộ lọc động (Spring Data JPA Specification)

```java
public class OrderSpecification {

    public static Specification<Order> withFilters(ReportFilterDto filter) {
        return (root, query, cb) -> {
            List<Predicate> predicates = new ArrayList<>();

            // Lọc theo khoảng thời gian
            predicates.add(cb.between(
                cb.function("DATE", LocalDate.class, root.get("createdAt")),
                filter.getFromDate(), filter.getToDate()
            ));

            // Lọc theo loại đơn
            if (filter.getOrderType() != OrderType.ALL) {
                predicates.add(cb.equal(root.get("orderType"), filter.getOrderType()));
            }

            // Lọc theo hình thức nhận (chỉ áp dụng cho đơn lẻ)
            if (filter.getDeliveryType() != DeliveryTypeFilter.ALL) {
                predicates.add(cb.equal(root.get("deliveryType"),
                    DeliveryType.valueOf(filter.getDeliveryType().name())));
            }

            // Chỉ tính đơn đã hoàn thành
            predicates.add(cb.equal(root.get("status"), OrderStatus.COMPLETED));

            return cb.and(predicates.toArray(new Predicate[0]));
        };
    }
}
```

## 4. Tích Hợp Chart.js Phía Frontend

### 4.1 Biểu đồ tròn — Phân bổ doanh thu

Dữ liệu lấy từ `summary.breakdown` trong JSON:

```javascript
// Chuẩn bị data từ API response
function buildRevenueChart(apiResponse) {
    const breakdown = apiResponse.summary.breakdown;

    const labels = breakdown.map(b => {
        if (b.orderType === 'WHOLESALE') return 'Bán sỉ';
        return b.deliveryType === 'PICKUP' ? 'Lẻ - Tự đến lấy' : 'Lẻ - Giao hàng';
    });

    const data = breakdown.map(b => b.totalAmount);

    new Chart(document.getElementById('revenueChart'), {
        type: 'doughnut',
        data: {
            labels,
            datasets: [{
                data,
                backgroundColor: ['#FF6384', '#36A2EB', '#FFCE56']
            }]
        },
        options: {
            plugins: {
                legend: { position: 'bottom' },
                tooltip: {
                    callbacks: {
                        label: ctx => `${ctx.label}: ${formatVnd(ctx.raw)}`
                    }
                }
            }
        }
    });
}
```

### 4.2 Biểu đồ cột — Top món bán chạy

Dữ liệu lấy từ `retailItems.banhMi`:

```javascript
function buildTopItemsChart(apiResponse) {
    // Gom nhóm bánh mì bơ đậu: cộng cả Sữa + Đường lại
    const items = apiResponse.retailItems.banhMi.reduce((acc, item) => {
        const key = item.name;
        acc[key] = (acc[key] || 0) + item.qtySold;
        return acc;
    }, {});

    const sorted = Object.entries(items)
        .sort((a, b) => b[1] - a[1])
        .slice(0, 5);  // Top 5

    new Chart(document.getElementById('topItemsChart'), {
        type: 'bar',
        data: {
            labels: sorted.map(([name]) => name),
            datasets: [{
                label: 'Số lượng bán ra',
                data: sorted.map(([, qty]) => qty),
                backgroundColor: '#36A2EB'
            }]
        },
        options: {
            indexAxis: 'y',   // Ngang — dễ đọc trên mobile
            plugins: { legend: { display: false } },
            scales: { x: { beginAtZero: true } }
        }
    });
}
```

### 4.3 Biểu đồ đường — Doanh thu 7 ngày gần nhất

Cần gọi API với khoảng thời gian 7 ngày và nhóm kết quả theo ngày:

```javascript
async function buildTrendChart() {
    const today = new Date();
    const from  = new Date(today);
    from.setDate(from.getDate() - 6);

    const res = await fetch(
        `/api/admin/analytics/daily-report` +
        `?fromDate=${formatDate(from)}&toDate=${formatDate(today)}&orderType=ALL`
    );
    const data = await res.json();

    // API cần trả thêm mảng dailyTotals khi query nhiều ngày
    const labels = data.dailyTotals.map(d => d.date);
    const values = data.dailyTotals.map(d => d.totalRevenue);

    new Chart(document.getElementById('trendChart'), {
        type: 'line',
        data: {
            labels,
            datasets: [{
                label: 'Doanh thu (VNĐ)',
                data: values,
                borderColor: '#FF6384',
                tension: 0.3,
                fill: true,
                backgroundColor: 'rgba(255, 99, 132, 0.1)'
            }]
        }
    });
}
```

| Sản phẩm | Topping/Size | TB 7 ngày | Gợi ý chuẩn bị |

| Bánh mì Heo quay | — | 35 | ~40 ổ |

| Bánh mì Bơ đậu | Đường | 6 | ~8 gói đường |
